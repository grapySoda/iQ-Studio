01 / GMSL FUNDAMENTALS

One cable, the whole link

GMSL (Gigabit Multimedia Serial Link) is a SerDes — serializer/deserializer — technology purpose-built for in-vehicle video. A serializer next to the sensor squeezes parallel MIPI data, a control channel, and power onto a single coax or shielded-twisted-pair (STP) cable. A deserializer at the SoC reverses it. 02 / MIPI FUNDAMENTALS

The on-board interface

MIPI Alliance defines the short-reach interfaces that live on the PCB. Two protocols dominate imaging: CSI-2 carries pixels from a camera into a processor; DSI drives pixels out to a display. Both ride on a physical layer — D-PHY or C-PHY.

SENSOR → HOST

CSI-2 — Camera Serial Interface

The dominant camera-to-SoC protocol. Transports RAW, RGB and YUV pixel data plus embedded metadata over 1–4 D-PHY lanes (or 1–3 C-PHY trios), using virtual channels to multiplex multiple streams down one link.

DSI — Display Serial Interface

The counterpart for screens — instrument clusters, CMS mirrors, in-cabin infotainment. Streams frames from the SoC to a panel, with a low-power command mode for configuration and a high-speed video mode for pixels.

D-PHY vs C-PHY

The PHY is the wire-level signaling. D-PHY uses differential pairs with a forwarded clock; C-PHY encodes the clock into a 3-wire symbol stream for more bits per pin.

D-PHY runs one clock lane plus 1–4 data lanes. Each lane is a differential pair (2 wires) toggling between a fast High-Speed mode and a power-saving Low-Power mode. Simple, ubiquitous, and the default for most sensors.

03 / PIPELINE ARCHITECTURE

Where GMSL meets MIPI

In a real automotive camera, both families work as a relay. MIPI CSI-2 moves pixels the few centimetres from sensor to serializer; GMSL carries them the several metres across the vehicle; MIPI CSI-2 hands them off again to the SoC. Hover or tap any stage to inspect it.

Stage

Image Sensor

WHY MIPI ON-BOARD

Cheap, native to sensors and SoCs, extremely high bandwidth over a few cm. But it tops out at ~20–30 cm of trace — useless across a car.

WHY GMSL ACROSS THE CAR

Survives 15 m of cable, EMI, and vibration; tunnels control + delivers power on the same wire. But it needs a SerDes pair, so it's reserved for the long haul.

THE HAND-OFF

The serializer is the bridge: MIPI in, GMSL out. To the sensor and SoC the link is "transparent" — they still speak pure CSI-2.
