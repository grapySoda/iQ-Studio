Applications

The fastest path from a booted device to a visible inference result — pick a demo, run one command, see it on screen. To customize a demo, see SDKs. To deploy your own trained model, see Model Deploy.

Demos

iQS-VLM
Vision-language model: live captions and Q&A on a UVC camera feed via the OGenie API.
iqs-vlm-demo
iQS-Streampipe
Multi-stream inference pipeline: run object detection across multiple concurrent video sources.
iqs-streampipe
iQS-YOLOv10n
YOLOv10n INT8 inference on GPU and NPU — a baseline for hardware acceleration comparison.
iqs-yolov10n

Launch commands

Every application is launched through iqs-launcher. The two-command pattern below brings up the OGenie server first, then the VLM demo client.

bash · vlm pair
iqs-launcher --autotag iqs-ogenie
iqs-launcher --autotag iqs-vlm-demo

For details on online vs. offline modes and air-gapped staging, see the iqs-launcher Reference.
