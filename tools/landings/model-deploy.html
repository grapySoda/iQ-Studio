Model Deploy

End-to-end guides for turning trained AI models into target-ready artifacts. The flow covers model quantization, model conversion, quality assurance, and on-target inference so you can move from a training artifact to deployable outputs with a guided process.

Model Deploy is powered by iQ-Foundry — a bring-your-own-model workflow. You start with your own custom trained model or a pre-trained artifact and use the iQ-Foundry flow to prepare it for the target platform.

Four stages

  1. Quantize the source model.
  2. Convert the model to a deployable format.
  3. Validate model quality with accuracy checks.
  4. Deploy and run inference on the target.

The workflow supports model optimization and quantization paths — including INT8 deployment — while aiming to preserve model quality.
